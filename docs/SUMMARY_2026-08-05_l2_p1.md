# 2026-08-05：L2 P1 — 车道级底图 · LCC · 拨杆变道 · FCW/AEB

## 目标

把 AutoSim 从「单路径 ACC 教学」推进到更接近 **L2 车道级** 的闭环：

1. 车道级地图（邻接 / 虚实线 / 后继）  
2. LCC（跟当前车道中心线）含拨杆变道  
3. 独立 FCW / AEB 纵向安全通道  
4. 高速 + 城市教学底图  

## 能力一览

| 能力 | 说明 |
|------|------|
| LaneMap | `Lane`：中心线、左右邻道、虚实线、`successor`；`lanes_from_centerline` adapter |
| `highway_3lane` | 三车道高速：虚线可换、实线禁换、限速分段 |
| `urban_arterial` | 城市主干 + 路口停车线 |
| LCC | Session 绑定 `ego_lane`；规划/PP 跟车道链中心线 |
| 拨杆变道 | Idle→Changing→Complete/Abort；smoothstep 过渡路径 |
| FCW/AEB | TTC + 净空；AEB 盖写 `acc`，优先于 ACC |
| 预设 | 默认 `highway_lcc`；另有 `highway_aeb`、`urban_arterial` |
| API | `action=lane_change`；`GET /api/maps`、`/api/basemap?map_id=` |

## 数据流（变道）

```text
Web [ / ] 或「左/右变道」
  → POST /api/control action=lane_change
  → LaneChangeManager.request(direction)
  → 检查 ACTIVE / 车速 / 虚线 / 邻道占用
  → 生成过渡 path → Pure Pursuit 横向跟随
  → 横向误差收敛 → 提交 ego_lane_id
  → _sim_log → HMI 事件日志
```

## 数据流（AEB）

```text
真值 / ACC leads
  → AEBController.evaluate
  → FCW 文言 或 AEB 减速度
  → acc = min(ACC_acc, AEB_acc)
  → world.step / 本地预测
```

## Snapshot 关键字段

| 字段 | 含义 |
|------|------|
| `ego_lane_id` / `lane_index` | 当前车道 |
| `lane_change` | 变道状态机载荷 |
| `aeb` | `{mode, d_gap, ttc}` |
| `accel` | 纵向加速度指令 (m/s²)；勿与 `acc`（跟车信息）混淆 |
| `view.cam_yaw` | 鸟瞰相机航向（跟道路中心线，不跟变道过渡曲线） |
| `hmi.alerts` | 事件日志（含 scene / 变道 / FCW / AEB / ACC 等） |

## 鸟瞰约定（易踩坑）

- **车体左侧 = +y**；屏幕左侧应对齐车体左侧（heading-up 下 `cx - left * scale`）。  
- **变道时**：自车横向位移正常；**相机 heading 锁道路**，避免过渡曲线拧画面。  
- **世界系车道线**：绑定 `lane_map_id` 时用 LaneMap 标线，不要用 path 居中挤出（否则变道看起来像没换道）。

## HMI 窗口（Web）

- 标题栏拖动；日志区 `overflow-y: auto`  
- 关键事件请用 `SimSession._sim_log(code, msg)`，勿 silent
